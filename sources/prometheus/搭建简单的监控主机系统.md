# 搭建promtheus监控环境

## 前提

需要事先安装docker和docker-compose

## docker-compose配置

程序安装使用docker-compose方式。
创建一个目录，名字随便，在目录下创建docker-compose.yml,docker-compose配置文件内容：

```yaml
version: '3'

networks:
  prom-net:
    driver: bridge

services:
  alertmanager:
    image: prom/alertmanager
    ports:
      - "9093:9093"
    volumes:
      - ./cfg/alertmanager/conf/alertmanager.yml:/etc/alertmanager/alertmanager.yml:rw
    container_name: alertmanager
    restart: always
    networks:
      - prom-net
    logging:
      driver: "json-file"
      options:
        max-size: "200m"
        max-file: "3"

  prometheus:
    image: prom/prometheus
    ports:
      - "9090:9090"
    volumes:
      - ./cfg/prometheus/conf/prometheus.yml:/etc/prometheus/prometheus.yml:rw
      - ./cfg/prometheus/conf:/etc/prometheus:rw
      - ./data/prometheus:/prometheus:rw
    container_name: prometheus
    command:  
    - --web.enable-lifecycle
    - --config.file=/etc/prometheus/prometheus.yml
    - --storage.tsdb.path=/prometheus
    - --web.console.libraries=/usr/share/prometheus/console_libraries
    - --web.console.templates=/usr/share/prometheus/consoles
    - --enable-feature=remote-write-receiver
    - --storage.tsdb.min-block-duration=2h
    - --storage.tsdb.max-block-duration=2h
    restart: always
    networks:
      - prom-net
    privileged: true
    logging:
      driver: "json-file"
      options:
        max-size: "200m"
        max-file: "3"

  grafana:
    image: grafana/grafana
    ports:
      - "3000:3000"
    volumes:
      - ./data/grafana/data:/var/lib/grafana:rw
    container_name: grafana
    restart: always
    privileged: true
    networks:
      - prom-net
    logging:
      driver: "json-file"
      options:
        max-size: "200m"
        max-file: "3"
  prometheus-webhook-dingtalk:
    image: timonwong/prometheus-webhook-dingtalk
    networks:
      - prom-net
    container_name: prometheus-webhook-dingtalk
    ports:
      - '8060:8060'
    volumes:
      - ./cfg/prometheus-webhook-dingtalk/conf/config.yml:/etc/prometheus-webhook-dingtalk/config.yml
      - ./cfg/prometheus-webhook-dingtalk/template:/etc/prometheus-webhook-dingtalk/template:rw
    restart: always
    logging:
      driver: "json-file"
      options:
        max-size: "200m"
        max-file: "3"
```

## prometheus配置文件

1. 编写prometheus配置文件位置放在docker-compose.yml文件的相对路径：./cfg/prometheus/conf/prometheus.yml，配置文件内容：
```yaml
global:
  scrape_interval:     30s
  evaluation_interval: 30s
  external_labels:
    region: moniForStack
    replica: 0
 
scrape_configs: 

  - job_name: node_exporter
    honor_timestamps: true
    metrics_path: /metrics
    scheme: http
    follow_redirects: true
    static_configs:
    - targets:
        - nodeIp:9100 # 需要修改的项，配置node-exporter的地址

# Alertmanager configuration
alerting:
  alertmanagers:
  - static_configs:
    - targets:
      - alertmanager:9093

rule_files:
  - "/etc/prometheus/rules/*.rules"
```

注意：prometheus配置文件中要配置node-exporter地址

2. 编写告警规则文件，位置放在docker-compose.yml文件的相对路径：./cfg/prometheus/conf/rules/node.rules，配置文件内容：
```yaml
groups:
- name: node
  rules:
  - alert: node_disk_read_too_fast
    expr: sum by (instance) (rate(node_disk_read_bytes_total[2m])) / 1024 / 1024 > 50
    for: 15s
    labels:
      severity: 1
      team: node
    annotations:
      summary: "{{ $labels.instance }} 的磁盘读取速率大于50MB！"
  - alert: node_disk_read_timeout
    expr: rate(node_disk_read_time_seconds_total[1m]) / rate(node_disk_reads_completed_total[1m]) > 0.1 and rate(node_disk_reads_completed_total[1m]) > 0
    for: 15s
    labels:
      severity: 1
      team: node
    annotations:
      summary: "{{ $labels.instance }} 磁盘延迟正在增长（读取已大于100ms）！"
  - alert: node_cpu_steal_too_big
    expr: avg by(instance) (rate(node_cpu_seconds_total{mode="steal"}[5m])) * 100 > 10
    for: 15s
    labels:
      severity: 1
      team: node
    annotations:
      summary: "{{ $labels.instance }} CPU steal大于10%，存在破坏性能的进程！"
  - alert: node_cpu_usage_too_big
    expr: 100 - (avg by(instance) (rate(node_cpu_seconds_total{mode="idle"}[2m])) * 100) > 80
    for: 15s
    labels:
      severity: 1
      team: node
    annotations:
      summary: "{{ $labels.instance }} CPU使用率大于80%！"
```
- [更多规则配置参考](http://git.koal.com/gw-xray/backend/gw-xray-server/-/tree/main/cfg/prometheus/conf/rules)

3. 创建数据存储目录，目录为docker-compose.yml文件的相对路径：./data/prometheus，需要给目录赋予777权限以免启动prometheus时报错
```shell
# chmod -R 777 ./data/prometheus
```

## alertmanager配置文件

编写alertmanager配置文件，位置放在docker-compose.yml文件的相对路径：./cfg/alertmanager/conf/alertmanager.yml

```yaml
global:
  resolve_timeout: 5m
route:
  group_by: ['instance']
  group_wait: 50s
  group_interval: 5m
  repeat_interval: 1d
  receiver: 'dingding'
  
receivers:
- name: 'dingding'
  # 钉钉配置
  webhook_configs:
  - url: http://prometheus-webhook-dingtalk:8060/dingtalk/ops/send # 这里是在钉钉开源组件中的接口，如果单独定义的receiver需要对应你的分组与钉钉机器人的webhook token

inhibit_rules:
  - source_match:
      alertname: '1'
    target_match:
      severity: '1'
    equal: ['alertname']
```

## prometheus-webhook-dingtalk配置文件

1. 编写prometheus-webhook-dingtalk配置文件，位置放在docker-compose.yml文件的相对路径：./cfg/prometheus-webhook-dingtalk/conf/config.yml
```yaml
# templates:
        # - contrib/templates/legacy/template.tmpl
  # 自定义模板路径
  #- /etc/prometheus-webhook-dingtalk/template/default.tmpl


## Targets, previously was known as "profiles"
# 定义的webhook，钉钉创建的webhook token
targets:
# 如果有多个分组就可以在这里定义多个接口
  ops:
    url: https://oapi.dingtalk.com/robot/send?access_token=a8efbb23afa8debf449f5a713ff801ff04e4e4152026173a06203745ac65653d  # 此处配置钉钉机器人地址
```

## grafana

grafana使用默认配置，需要创建数据存储目录，放在docker-compose.yml的相对路径：./data/grafana/data，给该目录赋予777权限，以免启动grafana失败：

```shell
# chmod -R 777 ./data/grafana/data
```

## 启动程序

上面配置完成后，就可以通过docker-compose启动这些docker容器了，在docker-compose.yml文件所在的目录下执行：

```shell
# docker-compose up -d
```

程序启动成功后，即可访问
- `prometheus界面`: http://服务器ip:9090/
- `grafana界面`: http://服务器ip:3000/
- `alertmanager界面`: http://服务器ip:9093/

## grafana加入图表

1. grafana加入prometheus数据源，在界面上操作。
2. 加入node-exporter图表。先从[node-exporter下载地址](https://grafana.com/grafana/dashboards/8919-1-node-exporter-for-prometheus-dashboard-cn-0413-consulmanager)下载图表的json配置，然后在grafana节点导入配置即可。
