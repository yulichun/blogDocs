# gw-xray

gw-xray项目的意义在于：

1. 探索各类监控技术，对比它们，并找到它们各自适用的场景
2. 整理网关监警需求
3. 实现监警系统，监警网关
4. 实现适配网关的最优监控方案，集成到网关
